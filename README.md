# partner-db

회사에서 엑셀 매크로로 관리하던 영업 업체 DB를 Spring Boot 웹 백오피스로 옮기는 개인 프로젝트입니다.

## 만든 이유

회사에서 영업할 업체 연락처를 엑셀 파일 하나로 관리하고 있습니다. 새 업체를 넣을 때마다 이미 있는 업체인지 Ctrl+F로 하나씩 찾아야 했고, 같은 업체에 두 번 연락하는 일이 생겼습니다.

그래서 VBA 매크로로 중복 검사와 등록을 자동화해 운영하고 있었는데, 엑셀이라 생기는 한계가 있었습니다.

- 한 사람만 파일을 열어 작업할 수 있음
- 마스터 시트를 실수로 직접 고쳐도 막을 수 없음
- 오래 연락하지 않은 업체를 찾으려면 매번 필터를 직접 걸어야 함

이 프로젝트는 엑셀 매크로에서 쓰던 규칙을 웹 화면과 DB로 옮기면서, 위 한계를 줄이는 것을 목표로 합니다.

## 기능

### 1단계 (완료)

- 업체 등록 · 목록 · 업체명 검색 · 수정 · 삭제
- 등록할 때 입력일(오늘)과 영업상태(미접촉) 자동 입력
- 구분(진행 / 문의 / 제외 / 구독취소)과 영업상태를 색으로 표시
- 처음 실행할 때 시연용 가짜 업체 10건 자동 입력

### 2단계 (진행 예정)

- 업체명 정리: `(주)ABC`, `ABC(주)`, `주식회사ABC`를 같은 업체로 판단
- 중복 검증: 이메일 · 전화번호 · 주소 등을 기존 업체와 대조해서 중복이면 등록을 막거나, 중복된 값만 비우고 등록
- 차단 규칙: 구독취소 · 진행 · 문의 · 제외 업체는 일반 등록에서 제외
- 미접촉 업체: 마지막 연락 후 일정 기간이 지난 업체만 모아 보기
- 업체 목록 JSON API

## 기술 스택

- Java 21
- Spring Boot 4.1
- Spring Data JPA
- Thymeleaf
- H2 Database (MySQL로 전환 예정)
- Gradle

## 구조

```
브라우저
  → PartnerController   주소를 받고 화면을 고름
  → PartnerService      등록 · 수정 규칙 (2단계 중복 검증도 여기에 들어감)
  → PartnerRepository   Spring Data JPA로 DB 저장 · 조회
  → DB (partner 테이블)
```

| 엑셀 | partner-db |
|---|---|
| 마스터DB 시트 | partner 테이블 |
| 시트의 한 행 | Partner 엔티티 |
| 신규입력 시트 + 이관 버튼 | 업체 등록 화면 |
| VBA 중복 검사 | PartnerService |

## 실행 방법

JDK 21이 필요합니다.

```
./gradlew bootRun
```

실행 후 브라우저에서 `http://localhost:8080`에 접속하면 됩니다.

DB 내용은 `http://localhost:8080/h2-console`에서 볼 수 있습니다. (JDBC URL: `jdbc:h2:~/partnerdb`, 사용자명: `sa`)

## 데이터 안내

저장소에 들어 있는 업체는 모두 시연용 가짜 데이터입니다. 실제 회사 업체 데이터는 저장소에 올리지 않습니다.
